### Step 2: Check if Card Should Be Saved

````php
**Storage Location:**
- The `save_card_requested` flag is stored in the `paymob_payments` table (BOOLEAN column)
- Set during payment initiation when user checks "Save this card"
- Read in webhook via: `$payment->save_card_requested`

```php
/**
 * Check if we should save card token.
 *
 * Conditions:
 * 1. Payment succeeded
 * 2. Payment method is CARD (not wallet)
 * 3. User opted in (checked "Save this card")
 * 4. Token exists in callback
 */
private function shouldSaveCardToken(PaymobPayment $payment, array $payload): bool
{
    // Only for card payments
    if ($payment->payment_method !== 'CARD') {
        return false;
    }

    // Check if user requested save (stored in paymob_payments.save_card_requested)
    if (!$payment->save_card_requested) {
        return false;
    }
    }

    // Verify token exists in Paymob response
    if (!isset($payload['source_data']['token'])) {
        Log::warning('Card save requested but no token in callback', [
            'payment_id' => $payment->id,
        ]);
        return false;
    }

    return true;
}
````

### Step 3: Extract and Save Token

```php
/**
 * Extract card token from callback and save to payment_methods table.
 */
private function saveCardToken(int $userId, array $payload): void
{
    try {
        // Use PaymobService to extract structured data
        $cardData = app(PaymobService::class)->extractCardTokenFromCallback($payload);

        if (!$cardData) {
            Log::warning('Failed to extract card data from callback', [
                'user_id' => $userId,
            ]);
            return;
        }

        // Calculate token fingerprint for duplicate detection
        $tokenFingerprint = hash('sha256', $cardData['token']);

        // Check if card already exists (by token fingerprint - safe deduplication)
        $exists = PaymentMethod::where('user_id', $userId)
            ->where('token_fingerprint', $tokenFingerprint)
            ->whereNull('deleted_at') // Only check non-deleted cards
            ->exists();

        if ($exists) {
            Log::info('Card already saved', [
                'user_id' => $userId,
                'last4' => $cardData['last4'],
            ]);
            return;
        }

        // Determine if this is first card (auto-default)
        $isFirstCard = PaymentMethod::where('user_id', $userId)->count() === 0;

        // Build expiry date if provided
        $expiresAt = null;
        if (isset($cardData['expiry_month']) && isset($cardData['expiry_year'])) {
            $expiresAt = Carbon::createFromFormat(
                'Y-m',
                $cardData['expiry_year'] . '-' . str_pad($cardData['expiry_month'], 2, '0', STR_PAD_LEFT)
            )->endOfMonth();
        }

        // Save card (token auto-encrypted + fingerprint auto-generated by model)
        $paymentMethod = PaymentMethod::create([
            'user_id' => $userId,
            'type' => 'card',
            'card_last_four' => $cardData['last4'],
            'card_brand' => $cardData['brand'],
            'token' => $cardData['token'], // ← Auto-encrypted + fingerprinted via setTokenAttribute()
            'is_default' => $isFirstCard,
            'is_verified' => true, // Verified since payment succeeded
            'expires_at' => $expiresAt,
        ]);

        Log::info('✅ Card saved successfully', [
            'payment_method_id' => $paymentMethod->id,
            'user_id' => $userId,
            'card_last_four' => $paymentMethod->card_last_four,
            'brand' => $paymentMethod->card_brand,
        ]);

    } catch (\Exception $e) {
        // Log but don't throw - card save failure shouldn't fail the payment
        Log::error('Failed to save card token', [
            'user_id' => $userId,
            'error' => $e->getMessage(),
        ]);
    }
}
```

## 🔍 PaymobService::extractCardTokenFromCallback() Details

```php
/**
 * Extract card token from Paymob webhook callback.
 *
 * @param array $callbackData - The webhook 'obj' payload
 * @return array|null
 */
public function extractCardTokenFromCallback(array $callbackData): ?array
{
    // Check if token exists
    if (!isset($callbackData['source_data']['token'])) {
        return null;
    }

    $sourceData = $callbackData['source_data'];

    return [
        'token' => $sourceData['token'],                              // e.g., "tok_abc123..."
        'last4' => $this->extractLast4Digits($sourceData['pan']),     // e.g., "4242"
        'brand' => $this->normalizeCardBrand($sourceData['sub_type']), // e.g., "visa"
        'expiry_month' => $sourceData['expiry_month'] ?? null,        // e.g., "12"
        'expiry_year' => $sourceData['expiry_year'] ?? null,          // e.g., "2025"
    ];
}
```

### Helper: Extract Last 4 Digits

Paymob sends PAN in various formats:

- `"424242XXXXXX4242"` (masked)
- `"4242"` (just last 4)
- `"424242******4242"`

We normalize to always get last 4 digits:

```php
private function extractLast4Digits(?string $pan): string
{
    if (!$pan) return '0000';

    // Remove non-digits
    $digitsOnly = preg_replace('/\D/', '', $pan);

    // Get last 4
    $last4 = substr($digitsOnly, -4);

    // Ensure 4 digits
    return str_pad($last4, 4, '0', STR_PAD_LEFT);
}
```

### Helper: Normalize Card Brand

Paymob sends various formats:

- `"VISA"`, `"Visa"`, `"visa"`
- `"MasterCard"`, `"Mastercard"`, `"MC"`
- `"American Express"`, `"AMEX"`

We normalize to our enum:

```php
private function normalizeCardBrand(string $paymobBrand): string
{
    return match(strtolower(trim($paymobBrand))) {
        'visa' => 'visa',
        'mastercard', 'master card', 'mc' => 'mastercard',
        'american express', 'amex' => 'amex',
        'discover' => 'discover',
        default => 'other',
    };
}
```

## 🗄️ Database Storage

### Before Encryption (in memory):

```php
$token = "tok_aBcDeFgHiJkLmNoPqRsTuVwXyZ123456"; // From Paymob
```

### After Encryption (in database):

```sql
SELECT token FROM payment_methods WHERE id = 1;
-- Result: "eyJpdiI6InRlc3QiLCJ2YWx1ZSI6ImFiYzEyMyIsIm1hYyI6InRlc3QifQ=="
```

The PaymentMethod model automatically:

1. **Encrypts** via `setTokenAttribute()` when saving
2. **Decrypts** via `getTokenAttribute()` when reading

### Example:

```php
// Save (auto-encrypts)
$pm = PaymentMethod::create([
    'token' => 'tok_abc123',  // Plaintext
]);

// Read (auto-decrypts)
echo $pm->token;  // Output: "tok_abc123" (decrypted)

// Database stores encrypted gibberish for PCI-DSS compliance
```

## 🔒 Security Guarantees

### ✅ What We Store:

- Encrypted Paymob token
- Last 4 digits (safe - PCI-DSS allows)
- Card brand (safe)
- Expiry date (safe)

### ❌ What We NEVER Store:

- Full card number (PAN)
- CVV/CVC
- Plaintext tokens
- Card PIN

### Encryption Details:

- **Algorithm**: AES-256-CBC
- **Key**: Laravel `APP_KEY` from `.env`
- **Library**: Laravel `Crypt` facade
- **Compliance**: PCI-DSS Level 1

## 📊 Integration Timeline

### First Payment (with "Save Card" checked):

```
User enters card → Payment initiated → Paymob iframe → User completes payment
↓
Paymob Webhook arrives → PaymentController::processedCallback()
↓
HMAC verified → Payment marked as PAID
↓
shouldSaveCardToken() → TRUE (user opted in)
↓
extractCardTokenFromCallback() → Extract token
↓
PaymentMethod::create() → Auto-encrypt token → Save to DB
↓
User sees "Card saved successfully" notification
```

### Second Payment (with saved card):

```
User selects saved card → No card entry form
↓
PaymentController::initiatePayment() with payment_method_id
↓
Load PaymentMethod → Auto-decrypt token
↓
PaymobService::payWithSavedCard(decrypted_token)
↓
Paymob charges saved card → May require 3DS
↓
Webhook arrives → Payment confirmed
```
